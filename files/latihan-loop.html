Latihan Fokus: Loop

Buka Console (F12). Tulis semua kodemu di <script> paling bawah, urut dari TODO 1.

TODO 1 — for dasar (naik)

Pakai for, cetak angka 1 sampai 10, satu per baris.

TODO 2 — for mundur (turun)

Pakai for, cetak angka 10 sampai 1 (hitung mundur). Petunjuk: mulai dari 10, syarat i >= 1, pakai i--.

TODO 3 — angka genap

Cetak semua angka genap dari 2 sampai 20. Boleh pakai i += 2, atau loop biasa + if (i % 2 === 0).

TODO 4 — akumulasi

Hitung TOTAL 1 + 2 + 3 + ... + 100 pakai pola total += i. Tampilkan hasilnya (harusnya 5050).

TODO 5 — counter + kondisi

Diberi const angka = [4, 7, 10, 3, 8, 15, 6]. Pakai loop untuk menghitung BERAPA BANYAK angka genap di dalamnya. Tampilkan jumlahnya (pakai pola counter ++).

TODO 6 — while

Mulai let saldo = 100000. Selama saldo >= 15000, kurangi 15000 tiap putaran dan cetak sisa saldo. Di akhir, tampilkan berapa kali kamu bisa mengurangi (pakai counter). Petunjuk: pakai while.

TODO 7 — loop array + akumulasi

Diberi const belanja = [12000, 5000, 8000, 20000]. Pakai loop (for atau for...of) untuk menghitung TOTAL belanja, lalu tampilkan.

TODO 8 (bonus) — nested loop

Pakai loop di dalam loop untuk mencetak segitiga bintang seperti ini:

*
**
***
****
*****

Petunjuk: loop luar mengatur baris (1–5), loop dalam mencetak `*` sebanyak nomor baris.
