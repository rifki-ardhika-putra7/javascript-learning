React useEffect + Fetch

useEffect sering dipakai untuk menjalankan efek samping, seperti mengambil data saat komponen pertama kali muncul.

Yang dipelajari

  • Menjalankan kode setelah render.
  • Mengambil data dari API saat komponen dimuat.
  • Menggunakan dependency array untuk mengontrol efek.

Contoh dasar

useEffect(() => {
  fetchData();
}, []);

Belajar Mandiri: React useEffect dan fetch

useEffect membuat React bisa berinteraksi dengan data eksternal.

Tujuan Pembelajaran

  • Menggunakan useEffect
  • Mengambil data API di React
  • Menangani loading dan error

Kenapa Materi Ini Penting

Banyak aplikasi modern menampilkan data dari server. useEffect adalah cara umum untuk itu.

Penjelasan Konsep

  • useEffect berjalan setelah render
  • fetch bisa dipakai di dalam effect
  • loading dan error state penting

Contoh Dasar

import { useEffect, useState } from 'react';

function Produk() {
  const [produk, setProduk] = useState(null);
  useEffect(() => {
    fetch('https://fakestoreapi.com/products/1')
      .then(res => res.json())
      .then(data => setProduk(data));
  }, []);
  return <div>{produk?.title}</div>;
}

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini membuat state untuk menyimpan data produk.
  2. Baris ini menjalankan fetch saat komponen pertama kali tampil.
  3. Output yang diharapkan adalah judul produk dari API yang muncul di layar.

Kesalahan Umum

  • Mengambil data tanpa dependency array
  • Lupa menampilkan loading saat data belum datang
  • Mengabaikan error dari fetch

Tips Debugging

  • Pakai dependency array agar efek tidak berjalan berulang
  • Tampilkan loading state saat pending
  • Coba API sederhana saat belajar
