React Dasar

React adalah library untuk membangun antarmuka pengguna dengan komponen yang dapat dipakai berulang kali.

Yang dipelajari

  • Komponen fungsi.
  • JSX sebagai sintaks untuk menulis UI.
  • Pemecahan tampilan menjadi bagian-bagian kecil.

Contoh dasar

function App() {
  return 
Halo React

Belajar Mandiri: React dasar

React membantu membangun UI yang lebih modular dan terstruktur.

Tujuan Pembelajaran

  • Memahami komponen fungsi
  • Mengenal JSX
  • Melihat perbedaan React dengan DOM biasa

Kenapa Materi Ini Penting

React banyak dipakai di industri karena memecah UI menjadi bagian kecil yang mudah dikelola.

Penjelasan Konsep

  • Komponen adalah fungsi yang mengembalikan UI
  • JSX mirip HTML, tapi bisa dipakai dengan JavaScript
  • React memanage UI berdasarkan state dan props

Contoh Dasar

function App() {
  return <h2>Halo React</h2>;
}

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini membuat komponen App.
  2. Baris ini mengembalikan elemen JSX.
  3. Output yang diharapkan adalah tampilan heading Halo React.

Kesalahan Umum

  • Menggunakan HTML biasa tanpa JSX
  • Lupa mengimpor React di proyek yang lama
  • Membuat komponen terlalu besar dari awal

Tips Debugging

  • Mulai dari komponen kecil
  • Coba satu komponen dulu
  • Bentuk pola pikir UI sebagai bagian-bagian kecil
