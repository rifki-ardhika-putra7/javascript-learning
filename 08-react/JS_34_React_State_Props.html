Belajar Mandiri: React state dan props

State dan props adalah inti interaksi React.

Tujuan Pembelajaran

  • Memahami state
  • Memahami props
  • Menghubungkan data antar komponen

Kenapa Materi Ini Penting

Interaksi UI biasanya bergantung pada data yang berubah, seperti counter, form, atau daftar tugas.

Penjelasan Konsep

  • useState membuat state
  • props membawa data ke komponen child
  • perubahan state memicu render ulang

Contoh Dasar

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini membuat state count.
  2. Baris ini mengubah state saat tombol diklik.
  3. Output yang diharapkan adalah tombol yang angka meningkat saat diklik.

Kesalahan Umum

  • Mengubah state langsung tanpa setter
  • Membingungkan props dan state
  • Tidak memahami kapan render ulang terjadi

Tips Debugging

  • Gunakan state untuk data yang berubah
  • Gunakan props untuk data yang datang dari luar
  • Coba satu contoh kecil dulu
