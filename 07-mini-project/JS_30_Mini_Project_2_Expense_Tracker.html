Mini Project 2: Expense Tracker

Expense tracker membantu mencatat pemasukan dan pengeluaran dengan data yang terstruktur.

Konsep yang diterapkan

  • Menggunakan array of objects untuk data transaksi.
  • Jumlah total dengan reduce().
  • Menampilkan daftar nama transaksi dengan map().

Contoh logika

const total = transaksi.reduce((acc, item) => acc + item.nominal, 0);

Belajar Mandiri: Mini project Expense Tracker

Expense tracker mengajarkan cara mengolah data nyata dengan JavaScript.

Tujuan Pembelajaran

  • Mencatat pemasukan dan pengeluaran
  • Menghitung total
  • Menampilkan data secara ringkas

Kenapa Materi Ini Penting

Aplikasi pencatatan pengeluaran sangat dekat dengan kebutuhan sehari-hari.

Penjelasan Konsep

  • Data transaksi
  • Perhitungan total
  • Filtering data

Contoh Dasar

const transaksi = [{ nama: 'Makan', nominal: 25000 }];
const total = transaksi.reduce((sum, item) => sum + item.nominal, 0);
console.log(total);

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini membuat data transaksi.
  2. Baris ini menjumlahkan semua nominal.
  3. Output yang diharapkan adalah total pengeluaran.

Kesalahan Umum

  • Menggunakan string untuk angka
  • Lupa membuat total ulang saat data berubah
  • Tidak memeriksa format input

Tips Debugging

  • Pastikan angka dikonversi ke number
  • Pecah kalkulasi ke fungsi kecil
  • Buat preview hasil sebelum tampil

Latihan Mandiri
