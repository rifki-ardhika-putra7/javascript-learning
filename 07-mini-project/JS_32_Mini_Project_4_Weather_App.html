Belajar Mandiri: Mini project Weather App

Weather app adalah latihan lengkap untuk data dinamis dan feedback pengguna.

Tujuan Pembelajaran

  • Mengambil data cuaca
  • Menampilkan kondisi cuaca
  • Menangani status error

Kenapa Materi Ini Penting

Aplikasi cuaca sangat dekat dengan kebutuhan sehari-hari dan sangat cocok untuk latihan fetch.

Penjelasan Konsep

  • Request data cuaca
  • Pesan loading
  • Penanganan error

Contoh Dasar

const kota = 'Bandung';
console.log(`Cuaca di ${kota} akan ditampilkan`);

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini menentukan kota yang ingin dicari.
  2. Output yang diharapkan adalah teks yang membangun konteks pencarian.

Kesalahan Umum

  • Lupa mengolah respons API
  • Tidak memeriksa apakah data ada
  • Mengabaikan fallback saat gagal

Tips Debugging

  • Periksa dokumentasi API
  • Tampilkan data minimal saat loading
  • Simpan kota favorit di localStorage jika perlu
