Mini Project 3: Movie Search App

Movie search app menggabungkan input pengguna, pencarian kata kunci, dan hasil data dari API.

Konsep yang diterapkan

  • Memproses kata kunci pengguna.
  • Memanggil API dengan fetch.
  • Menampilkan hasil ke halaman.

Contoh logika

const keyword = 'batman';
fetch(`https://example.com/search?q=${keyword}`);

Belajar Mandiri: Mini project Movie Search App

Movie search app menggabungkan banyak konsep interaksi dan data.

Tujuan Pembelajaran

  • Mencari data film
  • Menampilkan hasil pencarian
  • Menangani loading dan error

Kenapa Materi Ini Penting

Aplikasi pencarian film adalah contoh klasik untuk data async dan UI yang dinamis.

Penjelasan Konsep

  • Input pencarian
  • Request ke API
  • Rendering hasil

Contoh Dasar

const keyword = 'avengers';
console.log(`Mencari film: ${keyword}`);

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini menyiapkan kata kunci pencarian.
  2. Output yang diharapkan adalah teks pencarian yang muncul di console.

Kesalahan Umum

  • Tidak mengirim keyword dengan benar
  • Lupa menampilkan pesan saat hasil kosong
  • Tidak menangani error network

Tips Debugging

  • Beri delay kecil untuk pencarian
  • Tampilkan pesan jika tidak ada hasil
  • Coba API publik untuk ujicoba
