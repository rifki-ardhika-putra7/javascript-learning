Mini Project 1: Todo List

Todo list adalah contoh proyek sederhana yang menggabungkan array, DOM, dan logika penghapusan item.

Konsep yang diterapkan

  • Menyimpan daftar tugas dalam array.
  • Menambah dan menghapus item.
  • Menampilkan data ke halaman.

Contoh logika

todos.push('Belajar JavaScript');
const sisa = todos.filter(item => item !== 'Belajar CSS');

Belajar Mandiri: Mini project Todo List

Mini project ini menggabungkan banyak konsep dasar menjadi satu pengalaman belajar.

Tujuan Pembelajaran

  • Membuat daftar tugas
  • Menambah dan menghapus item
  • Menyimpan state di browser

Kenapa Materi Ini Penting

Project ini sangat bagus untuk melihat bagaimana semua konsep dasar bekerja bersama.

Penjelasan Konsep

  • Input user
  • List item
  • State local

Contoh Dasar

const todos = ['Belajar JS'];
todos.push('Latihan DOM');
console.log(todos);

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini membuat daftar tugas awal.
  2. Baris ini menambahkan item baru.
  3. Output yang diharapkan adalah daftar tugas dengan dua item.

Kesalahan Umum

  • Tidak memperbarui tampilan saat data berubah
  • Menghapus item dari indeks yang salah
  • Tidak menyimpan data saat halaman reload

Tips Debugging

  • Buat fitur satu per satu
  • Cek data sebelum menampilkannya
  • Jangan lupa simpan hasil kerja user
