JS 8: Event Handling

Event adalah peristiwa pengguna yang dapat ditangani untuk membuat aplikasi web menjadi interaktif.

Menangani klik

const tombol = document.querySelector('#tombol');

tombol.addEventListener('click', function() {
  alert('Tombol diklik!');
});

Input dan submit

const input = document.querySelector('#nama');
input.addEventListener('input', function(event) {
  console.log(event.target.value);
});

const form = document.querySelector('form');
form.addEventListener('submit', function(event) {
  event.preventDefault();
  console.log('Form dikirim');
});

Event object

document.body.addEventListener('keydown', (event) => {
  console.log('Tombol:', event.key);
});

Event object memberi informasi seperti target, key, dan tipe event.

Belajar Mandiri: Event handling

Event membuat aplikasi terasa responsif.

Tujuan Pembelajaran

  • Menambahkan event listener
  • Memahami alur event
  • Membuat interaksi sederhana

Kenapa Materi Ini Penting

Kebanyakan aplikasi web interaktif bekerja lewat event. Tanpa event, halaman hanya tampil statis.

Penjelasan Konsep

  • addEventListener menangkap event
  • event target memberi tahu elemen yang dipicu
  • satu elemen bisa punya banyak event

Contoh Dasar

const tombol = document.querySelector('button');
tombol.addEventListener('click', () => {
  alert('Tombol diklik');
});

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini memilih tombol.
  2. Baris ini menambahkan aksi saat tombol diklik.
  3. Output yang diharapkan adalah popup muncul saat tombol ditekan.

Kesalahan Umum

  • Lupa menambahkan listener
  • Menggunakan onclick padahal addEventListener lebih fleksibel
  • Tidak memeriksa elemen target

Tips Debugging

  • Pakai event delegation saat elemen banyak
  • Jangan menumpuk event secara acak
  • Coba event klik, input, dan submit
