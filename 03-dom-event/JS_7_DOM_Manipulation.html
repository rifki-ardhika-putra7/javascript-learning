JS 7: Manipulasi DOM

DOM adalah representasi halaman HTML yang bisa dimanipulasi dengan JavaScript.

Mengambil elemen

const judul = document.querySelector('h1');
const semuaParagraf = document.querySelectorAll('p');
const tombol = document.getElementById('tombol');

Mengubah konten

judul.textContent = 'Halo JavaScript!';
const pesan = document.createElement('p');
pesan.textContent = 'Ini paragraf baru.';
document.body.appendChild(pesan);

Mengubah kelas dan atribut

tombol.classList.add('aktif');
tombol.setAttribute('type', 'button');

if (tombol.classList.contains('aktif')) {
  console.log('Tombol aktif');
}

Belajar Mandiri: Manipulasi DOM

DOM membuat halaman web bisa berubah sesuai interaksi pengguna.

Tujuan Pembelajaran

  • Mengambil elemen HTML
  • Mengubah teks dan atribut
  • Memahami konsep DOM

Kenapa Materi Ini Penting

Interaktivitas web sering dimulai dari mengubah elemen di halaman, misalnya mengisi nama pengguna atau menampilkan hasil.

Penjelasan Konsep

  • document.querySelector memilih elemen
  • textContent mengubah teks
  • classList mengubah class

Contoh Dasar

const judul = document.querySelector('h1');
judul.textContent = 'Halo, dunia!';

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini mencari elemen h1.
  2. Baris ini mengganti teks yang tampil di halaman.
  3. Output yang diharapkan adalah judul halaman berubah.

Kesalahan Umum

  • Memilih elemen yang tidak ada
  • Menulis script sebelum elemen tersedia
  • Mengubah DOM tanpa membagi tugas

Tips Debugging

  • Pastikan script dijalankan setelah elemen ada
  • Pakai querySelector yang spesifik
  • Cek elemen dengan console sebelum mengubahnya
