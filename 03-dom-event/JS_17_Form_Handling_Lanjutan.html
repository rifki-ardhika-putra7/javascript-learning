Form Handling Lanjutan

Form handling membantu menahan submit default, memvalidasi input, dan menyiapkan data sebelum dikirim.

Yang dipelajari

  • preventDefault() untuk menghentikan submit bawaan.
  • Validasi input seperti nama dan email.
  • Menampilkan pesan error yang jelas kepada pengguna.

Contoh dasar

form.addEventListener('submit', (event) => {
  event.preventDefault();
  console.log('form dikirim');
});

Belajar Mandiri: Form handling lanjutan

Form yang baik membuat interaksi terasa profesional.

Tujuan Pembelajaran

  • Memvalidasi input lebih rapi
  • Mengatur submit form
  • Membuat pesan kesalahan yang jelas

Kenapa Materi Ini Penting

Pengalaman pengguna sangat dipengaruhi oleh form yang mudah dipahami dan tidak membingungkan.

Penjelasan Konsep

  • Memeriksa nilai input
  • Menampilkan feedback
  • Mengelola submit event

Contoh Dasar

const input = document.querySelector('input');
input.addEventListener('input', () => {
  console.log('User sedang mengetik');
});

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini memilih input.

Kesalahan Umum

  • Mengabaikan nilai input sebelum dipakai
  • Tidak memberi pesan error
  • Membuat validasi yang terlalu kaku

Tips Debugging

  • Beri pesan yang ramah
  • Cek input secara bertahap
