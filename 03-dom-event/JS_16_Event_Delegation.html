Event Delegation

Event delegation adalah teknik menaruh satu event listener di parent, sehingga elemen anak yang muncul dinamis tetap bisa ditangani.

Kenapa penting

  • Memudahkan menangani banyak tombol atau elemen.
  • Hemat kode dibanding menambahkan listener ke setiap elemen.
  • Sangat berguna saat daftar data berubah secara dinamis.

Contoh dasar

parent.addEventListener('click', (event) => {
  if (event.target.matches('button')) {
    console.log('button diklik');
  }
});

Belajar Mandiri: Event delegation

Delegation membantu kode tetap rapi saat elemen bertambah banyak.

Tujuan Pembelajaran

  • Memahami konsep delegation
  • Mengurangi listener yang berlebihan
  • Membuat UI dinamis

Kenapa Materi Ini Penting

Saat elemen ditambahkan secara dinamis, event delegation membuat penanganan lebih efisien.

Penjelasan Konsep

  • Event bubbling
  • Parent menangani event anak
  • Cocok untuk list yang sering berubah

Contoh Dasar

document.body.addEventListener('click', (event) => {
  if (event.target.matches('button')) {
    console.log('Tombol ditekan');
  }
});

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini menambahkan listener di body.
  2. Baris ini memeriksa apakah elemen yang diklik adalah tombol.
  3. Output yang diharapkan adalah log saat tombol diklik.

Kesalahan Umum

  • Menambahkan listener ke setiap tombol satu per satu
  • Lupa memeriksa target
  • Tidak memahami bubbling

Tips Debugging

  • Pakai delegation untuk daftar dinamis
  • Cek event.target dengan teliti
  • Coba visualisasikan bubbling di kepala
