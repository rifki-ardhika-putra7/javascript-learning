Module JavaScript

Module membantu memecah kode menjadi bagian-bagian kecil yang bisa dipakai ulang dan diorganisir.

Yang dipelajari

  • export untuk mengekspor fungsi atau nilai.
  • import untuk memakai fungsi dari file lain.
  • Memisahkan kode agar lebih rapi.

Contoh dasar

export function halo() {
  console.log('Halo');
}

Belajar Mandiri: Module JavaScript

Module membuat proyek JavaScript lebih scalable.

Tujuan Pembelajaran

  • Memahami export dan import
  • Memecah kode ke file yang berbeda
  • Membuat aplikasi lebih rapi

Kenapa Materi Ini Penting

Saat proyek berkembang, satu file besar menjadi sulit dikelola. Module membantu memecah tanggung jawab.

Penjelasan Konsep

  • export menyiapkan nilai yang bisa dipakai file lain
  • import mengambil nilai tersebut
  • module menjaga kode lebih terstruktur

Contoh Dasar

export function tambah(a, b) {
  return a + b;
}

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini menandai fungsi sebagai bagian yang bisa dipakai file lain.
  2. Output yang diharapkan adalah fungsi siap diimport dari file lain.

Kesalahan Umum

  • Lupa menambahkan type=module saat memakai module di browser
  • Mencampur kode yang seharusnya dipisah
  • Mengimpor terlalu banyak hal

Tips Debugging

  • Pecah berdasarkan fungsi
  • Jangan membuat file terlalu kecil
  • Gunakan nama file yang jelas
