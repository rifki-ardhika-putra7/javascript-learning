NPM Dasar

NPM adalah package manager yang dipakai untuk menginstal library dan menjalankan proyek JavaScript.

Yang dipelajari

  • npm init -y untuk membuat file konfigurasi proyek.
  • npm install untuk memasang dependency.
  • npm run untuk menjalankan script.

Contoh perintah

npm install lodash
npm run dev

Belajar Mandiri: NPM dasar

NPM membantu mengelola ekosistem JavaScript dengan rapi.

Tujuan Pembelajaran

  • Memahami package.json
  • Menginstal package
  • Mengerti peran npm scripts

Kenapa Materi Ini Penting

Banyak proyek modern bergantung pada package. NPM memudahkan instalasi dan pembaruan.

Penjelasan Konsep

  • npm init membuat proyek
  • npm install menambah package
  • package.json mencatat dependensi

Contoh Dasar

npm install lodash

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini mengunduh package lodash.
  2. Output yang diharapkan adalah package tersedia di project Anda.

Kesalahan Umum

  • Menginstal package di folder yang salah
  • Tidak memeriksa package.json
  • Menghapus node_modules tanpa alasan

Tips Debugging

  • Jangan instal package yang tidak dibutuhkan
  • Baca dokumentasi package sebelum dipakai
  • Pakai npm scripts untuk perintah rutin
