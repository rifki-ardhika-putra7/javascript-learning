Git & GitHub

Git dan GitHub membantu mengelola versi kode dan bekerja sama dengan tim secara terorganisir.

Yang dipelajari

  • git init untuk memulai repositori.
  • git add dan git commit untuk menyimpan perubahan.
  • git push untuk mengirim kode ke GitHub.

Contoh perintah

git add .
git commit -m "first commit"
git push origin main

Belajar Mandiri: Git dan GitHub

Git dan GitHub sangat penting untuk manajemen proyek kode.

Tujuan Pembelajaran

  • Memahami commit, branch, dan push
  • Menyimpan projek di GitHub
  • Berbagi kode dengan orang lain

Kenapa Materi Ini Penting

Versi kode yang teratur sangat penting saat bekerja sendiri maupun tim.

Penjelasan Konsep

  • Commit adalah snapshot perubahan
  • Branch memisahkan alur kerja
  • Push mengirim perubahan ke remote

Contoh Dasar

git init
git add .
git commit -m 'Awal project'

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini menginisialisasi repositori.
  2. Baris ini menyiapkan semua perubahan untuk dicatat.
  3. Output yang diharapkan adalah commit baru tercipta.

Kesalahan Umum

  • Lupa menambahkan file sebelum commit
  • Membuat terlalu banyak commit yang tidak jelas
  • Tidak memahami branch

Tips Debugging

  • Beri pesan commit yang jelas
  • Commit kecil dan sering
  • Jangan simpan file sensitif di repo
