Vite

Vite adalah alat build modern yang sangat cepat untuk menjalankan proyek frontend berbasis JavaScript.

Yang dipelajari

  • Membuat proyek baru dengan perintah Vite.
  • Menjalankan server pengembangan.
  • Memahami workflow frontend modern.

Contoh perintah

npm create vite@latest nama-proyek
cd nama-proyek
npm install
npm run dev
