JS 9: Asynchronous, Promise, Fetch

Asynchronous membuat JavaScript bisa menjalankan tugas di latar belakang tanpa menghentikan halaman.

setTimeout

console.log('Mulai');
setTimeout(() => {
  console.log('Tertunda 2 detik');
}, 2000);
console.log('Selesai');

Promise

const janji = new Promise((resolve, reject) => {
  const sukses = true;
  if (sukses) {
    resolve('Berhasil');
  } else {
    reject('Gagal');
  }
});

janji
  .then(data => console.log(data))
  .catch(err => console.error(err));

Async/Await dan Fetch

async function ambilData() {
  try {
    const respons = await fetch('https://jsonplaceholder.typicode.com/todos/1');
    const data = await respons.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

ambilData();

Belajar Mandiri: Asynchronous, promise, dan fetch

Async membantu aplikasi tetap responsif saat menunggu data.

Tujuan Pembelajaran

  • Memahami konsep asynchronous
  • Menggunakan promise
  • Membuat request dengan fetch

Kenapa Materi Ini Penting

Banyak aplikasi modern bergantung pada data dari internet. Kita perlu tahu cara menangani waktu tunggu.

Penjelasan Konsep

  • Kode async tidak selalu berjalan lurus
  • Promise mewakili proses yang belum selesai
  • fetch mengambil data dari API

Contoh Dasar

fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(res => res.json())
  .then(data => console.log(data.title));

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini memulai request ke API.
  2. Baris ini mengubah respons menjadi format JSON.
  3. Output yang diharapkan adalah judul postingan dari API.

Kesalahan Umum

  • Menganggap fetch langsung memberikan data siap pakai
  • Lupa menangani error
  • Membuat banyak request tanpa perlu

Tips Debugging

  • Gunakan async/await untuk kode yang lebih rapi
  • Selalu cek status respons
  • Tampilkan loading saat data sedang diambil

Latihan Mandiri

Ambil data dari API sederhana lalu tampilkan di halaman.
