Error Handling

Kesalahan dalam program bisa dicegah atau ditangani dengan try dan catch.

Kenapa penting

  • Mencegah aplikasi berhenti tiba-tiba.
  • Membantu menampilkan pesan error yang lebih jelas.
  • Sering dipakai saat parsing JSON atau mengakses data API.

Contoh dasar

try {
  console.log(data);
} catch (error) {
  console.log(error.message);
}

Belajar Mandiri: Error handling

Error handling membuat aplikasi lebih kuat dan user-friendly.

Tujuan Pembelajaran

  • Menggunakan try/catch
  • Menangani error dengan rapi
  • Membuat aplikasi tidak rusak

Kenapa Materi Ini Penting

Tanpa penanganan error, aplikasi bisa berhenti atau menampilkan hal yang membingungkan.

Penjelasan Konsep

  • try menjalankan kode yang berisiko
  • catch menangkap error
  • finally selalu jalan

Contoh Dasar

try {
  const hasil = JSON.parse('{bad json}');
} catch (error) {
  console.log('Ada error:', error.message);
}

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini mencoba mengubah string JSON.
  2. Baris ini menangkap error jika parsing gagal.
  3. Output yang diharapkan adalah pesan error yang jelas.

Kesalahan Umum

  • Mengabaikan error
  • Menangkap error terlalu luas
  • Tidak memberi feedback ke user

Tips Debugging

  • Tangani error yang relevan
  • Beri pesan yang mudah dipahami
  • Coba simulasi error secara sengaja untuk melihat hasilnya
