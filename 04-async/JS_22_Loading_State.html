Loading State

Loading state memberi feedback kepada pengguna saat proses sedang berjalan, misalnya saat mengambil data dari server.

Yang dipelajari

  • Memperbarui teks atau UI saat proses dimulai.
  • Menggunakan setTimeout() atau async untuk simulasi proses.
  • Memberi tampilan yang lebih nyaman saat data belum selesai.

Contoh dasar

status.textContent = 'Memuat...';
setTimeout(() => {
  status.textContent = 'Selesai';
}, 1000);

Belajar Mandiri: Loading state

Loading state membuat aplikasi terasa lebih profesional.

Tujuan Pembelajaran

  • Menampilkan status loading
  • Membuat UX yang lebih nyaman
  • Mengelola keadaan sementara

Kenapa Materi Ini Penting

Tanpa loading state, user bisa mengira aplikasi macet.

Penjelasan Konsep

  • Loading biasanya tampil saat proses dimulai
  • State diubah menjadi selesai saat data datang
  • Feedback visual sangat penting

Contoh Dasar

let loading = true;
setTimeout(() => {
  loading = false;
  console.log('Selesai');
}, 1000);

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini membuat status loading awal.
  2. Baris ini mengubah status setelah satu detik.
  3. Output yang diharapkan adalah selesai setelah delay.

Kesalahan Umum

  • Tidak memberi feedback sama sekali
  • Mengubah state terlalu cepat atau terlalu lambat
  • Tidak menghapus loading saat selesai

Tips Debugging

  • Pakai loading untuk operasi yang butuh waktu
  • Tampilkan pesan kosong saat data tidak ada
  • Jangan lupa hilangkan loading saat selesai

Latihan Mandiri

Buat indikator loading sederhana saat menunggu 2 detik.
