Fetch API Lanjutan

Fetch API digunakan untuk mengambil data dari server atau layanan API secara asynchronous.

Yang dipelajari

  • fetch() untuk mengirim request.
  • response.json() untuk mengubah respons menjadi object.
  • catch() untuk menangani error.

Contoh dasar

fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(res => res.json())
  .then(data => console.log(data));

Belajar Mandiri: Fetch API lanjutan

Fetch API adalah fondasi interaksi data modern.

Tujuan Pembelajaran

  • Menggunakan fetch dengan data lebih kompleks
  • Memahami method GET dan POST
  • Membuat request yang lebih profesional

Kenapa Materi Ini Penting

Aplikasi modern sering mengirim dan menerima data dari backend. Fetch adalah alat utama untuk itu.

Penjelasan Konsep

  • GET untuk membaca data
  • POST untuk mengirim data
  • Header dan body penting saat request kompleks

Contoh Dasar

fetch('https://jsonplaceholder.typicode.com/posts', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: 'Belajar fetch' })
});

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini mengirim request POST.
  2. Baris ini memberi tahu server format datanya.
  3. Output yang diharapkan adalah response dari server setelah request dikirim.

Kesalahan Umum

  • Lupa mengirim header
  • Tidak menangani response yang gagal
  • Menganggap semua API bisa dipakai tanpa batas

Tips Debugging

  • Periksa dokumentasi API
  • Cek status response
  • Buat kode fallback saat request gagal
