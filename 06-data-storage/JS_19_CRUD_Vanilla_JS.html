CRUD Vanilla JS

CRUD adalah singkatan dari Create, Read, Update, dan Delete, konsep dasar yang sering dipakai saat mengolah data.

Yang dipelajari

  • push() untuk menambah data.
  • splice() untuk menghapus data.
  • Pengubahan nilai array secara langsung untuk update.

Contoh dasar

let daftar = ['Belajar JS'];
daftar.push('Belajar CSS');
console.log(daftar);

Belajar Mandiri: CRUD vanilla JavaScript

CRUD adalah pola yang sering dipakai dari aplikasi sederhana sampai aplikasi besar.

Tujuan Pembelajaran

  • Membuat fitur tambah
  • Membaca data
  • Mengedit dan menghapus data

Kenapa Materi Ini Penting

Banyak aplikasi web berisi data yang bisa dikelola oleh user. CRUD adalah dasar dari itu semua.

Penjelasan Konsep

  • Create menambah data
  • Read menampilkan data
  • Update mengubah data
  • Delete menghapus data

Contoh Dasar

const daftar = ['buku'];
daftar.push('pensil');
console.log(daftar);

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini membuat array daftar.
  2. Baris ini menambah item baru ke akhir array.
  3. Output yang diharapkan adalah ["buku", "pensil"].

Kesalahan Umum

  • Langsung menghapus elemen dari array tanpa memeriksa indeks
  • Lupa memperbarui tampilan setelah perubahan data
  • Membuat logika edit yang rumit

Tips Debugging

  • Pisahkan data dari tampilan
  • Perbarui DOM setelah data berubah
  • Coba satu fitur CRUD dahulu
