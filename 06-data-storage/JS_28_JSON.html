JSON

JSON adalah format pertukaran data yang sering dipakai untuk mengirim dan menerima data dari API.

Yang dipelajari

  • JSON.stringify() untuk mengubah object menjadi string.
  • JSON.parse() untuk mengubah string menjadi object.
  • Format data yang umum dipakai di web modern.

Contoh dasar

const data = { nama: 'Dina' };
const json = JSON.stringify(data);

Belajar Mandiri: JSON

JSON adalah format yang sangat umum di web modern.

Tujuan Pembelajaran

  • Memahami struktur JSON
  • Mengubah data JavaScript ke JSON
  • Membaca JSON dari API

Kenapa Materi Ini Penting

Banyak API mengirim data dalam format JSON. Kita perlu bisa membaca dan mengolahnya.

Penjelasan Konsep

  • JSON memakai string kunci dan nilai
  • JSON.stringify mengubah objek ke string
  • JSON.parse mengubah string ke objek

Contoh Dasar

const data = JSON.stringify({ nama: 'Bima', umur: 21 });
console.log(data);

Contoh Kasus Nyata

Bayangkan kamu sedang mengolah data mahasiswa, daftar belanja, catatan tugas, atau hasil pencarian film. Materi ini membantu kamu mengubah data tersebut menjadi antarmuka yang lebih berguna.

Cara Membaca Kode

  1. Baris ini mengubah objek menjadi string JSON.
  2. Output yang diharapkan adalah teks JSON.

Kesalahan Umum

  • Menganggap JSON adalah JavaScript object
  • Lupa memberi tanda kutip pada string JSON
  • Menyimpan data berlebihan

Tips Debugging

  • Periksa format data dengan teliti
  • Gunakan JSON.parse saat menerima data dari API
  • Coba lihat data nyata dari contoh API
