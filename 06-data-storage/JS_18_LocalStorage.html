LocalStorage

LocalStorage memungkinkan aplikasi menyimpan data di browser sehingga tetap ada meski halaman direfresh.

Yang dipelajari

  • setItem() untuk menyimpan data.
  • getItem() untuk membaca data.
  • removeItem() untuk menghapus data.

Contoh dasar

localStorage.setItem('nama', 'Dina');
console.log(localStorage.getItem('nama'));

Belajar Mandiri: LocalStorage

LocalStorage cocok untuk data sederhana yang ingin bertahan di browser.

Tujuan Pembelajaran

  • Menyimpan data di browser
  • Memahami keterbatasan localStorage

Kenapa Materi Ini Penting

Sangat berguna untuk catatan sederhana, preferensi, dan daftar tugas yang ingin dipertahankan.

Penjelasan Konsep
